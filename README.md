# ⏳ TimeSync — Appointment & Service Management

**TimeSync** is a full-featured platform built with Laravel for real-time management of appointments, clients, and services. The system features a modern, 100% responsive (Mobile First) interface, an administrative dashboard, and REST API integration supported by Laravel Sanctum.

---

## 🛠️ Technologies Used

- **PHP 8.3+** & **Laravel 11 / 13**
- **Blade Components** (SSR with Dark Mode support)
- **Tailwind CSS** (Responsive Design & Modern UI)
- **SQLite / MySQL**
- **Laravel Sanctum** (Token-based API Authentication)

---

## 🚀 Key Features

- 📱 **100% Responsive UI:** Layout designed to adapt seamlessly across mobile devices, tablets, and desktops.
- 🗓️ **Appointment Management:** Real-time scheduling, status updates, and service listing.
- 📖 **API Documentation:** Built-in interactive view (`/api-docs`) detailing REST endpoints for mobile app integration (Flutter / React Native).
- 🔑 **Secure Authentication:** Login, session handling, and API access tokens via Sanctum.
- 🧪 **Database Seeding:** Configured Seeders and Factories for instant demo data generation.
